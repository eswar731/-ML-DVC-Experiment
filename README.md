# -ML-DVC-Experiment
Machine Learning experiment demonstrating Git and DVC for dataset, model, and experiment versioning, including Random Forest model comparison, DVC metrics, hyperparameter tracking, and reproducible ML pipelines.


This project implements an end-to-end Machine Learning workflow using Git and DVC. It demonstrates dataset versioning, model versioning, hyperparameter tracking using params.yaml, metric comparison between model versions, and experiment reproducibility using dvc repro. Two versions of the dataset and Random Forest model are maintained and compared using Accuracy, Precision, Recall, and F1-score.
